# Profile Photo

Place your profile photo here with one of these filenames:

- `profile-photo.jpg` (recommended)
- `profile-photo.jpeg`
- `profile-photo.png`
- `profile-photo.webp`

The image will be displayed as a circular profile picture in the hero section.

**Recommended specifications:**
- Square format (1:1 aspect ratio)
- Minimum size: 400x400 pixels
- File size: Under 500KB for best performance
